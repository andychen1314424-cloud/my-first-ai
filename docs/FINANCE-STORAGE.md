# ZX Finance 本地存储

真实账本单独保存在 `.data/finance.sqlite`（可由 `ZX_DATA_DIR` 改目录），不会从 Claude 的演示数据层迁移账户、余额、负债或流水。新库仅有常用分类；`isDemo` 恒为 `false`。项目实验台继续使用自己的 `projects.sqlite`。

## 账务规则

所有金额为安全整数分。账户表保存初始余额，每次快照都从初始余额和全部流水计算当前余额；不维护可漂移的余额缓存。允许现金负余额，以便录入历史和透支；负余额不是新增借款。需要透支自动建负债的产品规则尚未实现。

支出减少现金并计消费，退款增加现金并冲减消费；收入增加现金；转账同时减少转出现金和增加转入现金，不计收支；还款同时减少现金、负债余额与本期应还，不计消费。退款本轮是独立的支出冲减记录，尚无原始交易关联与部分退款上限。还款对应一个固定的应还期间，尚不自动生成下期账单、计息或拆分本金利息。

本轮可创建投资、固定资产、应收款账户并记录其初始余额，但这些不是持仓账本；投资买卖、借入、借出和收回类型明确拒绝，不会冒充普通消费或忽略现金变化。新增负债仅有内部存储方法供测试与下一阶段对接，暂无用户界面及 HTTP 新增接口。

每次新增、修改、删除、预算更新和账户创建均在 `BEGIN IMMEDIATE` 中完成：关联校验、流水修改、全量余额与还款校验、审计、幂等凭证一起提交或回滚。快照使用只读事务，避免跨表读出不同版本。SQLite 开启外键、STRICT、WAL、FULL synchronous 和 3 秒 busy timeout。单用户本地用途，不支持多租户与用户授权隔离。

`Idempotency-Key` 必须是 1–128 位字母、数字或 `._:-`。新增交易和还款分别按操作类型和键去重：同键同规范化请求返回原结果；同键不同请求返回 409。凭证写入数据库，重启仍生效；编辑或删除原流水也不释放该键。失败事务不占用键。客户端不能把手动数据伪装为 AI 或账单导入来源。

`finance_audit` 保存本地创建、修改、删除前后的记录和时间；通过 HTTP 无法修改。拥有电脑文件权限的人仍能更改数据库，审计不是防篡改签名账本。数据库含敏感备注，应与备份一起妥善保管且不提交 Git。

## 迁移、备份与回滚

`finance_schema_migrations` 记录版本、DDL SHA-256 和应用时间。当前版本为 1。首次开启在一个事务中建表并插入分类；重复开启校验版本和校验和，不重复插入。高于代码支持版本的数据库、校验和不符的数据库拒绝打开。以后新增迁移必须追加版本，不能改写已应用的 DDL。

在应用目录运行 `node scripts/finance-backup.ts`。使用 Node 原生 SQLite online backup 创建独立一致性快照，再执行 `integrity_check` 与 `foreign_key_check`。备份只写到被 Git 忽略的 `.data/backups/`（或 `ZX_DATA_DIR/backups/`），不覆盖已有备份。WAL 运行期间不要仅复制主文件。该机制是手动备份，不是自动备份调度，也未做加密或异地复制。

尚未录入任何用户数据的新库可运行 `node scripts/finance-backup.ts --rollback-empty`：先备份，然后事务回滚 v1 表到 v0。含账户、流水、负债、预算、审计或幂等记录时明确拒绝破坏性降级。恢复业务数据使用备份恢复流程，不运行 DROP TABLE。

恢复流程：停止本应用及所有访问该库的进程；保留当前 `finance.sqlite`、`finance.sqlite-wal` 与 `finance.sqlite-shm` 到单独的本地恢复目录；确认备份的 `PRAGMA integrity_check` 返回 `ok`、`PRAGMA foreign_key_check` 为空，且迁移版本受当前代码支持；将备份复制为 `.data/finance.sqlite`，不要把旧 WAL/SHM 放回新库旁；重新启动并核对账户和记录。`ZX_DATA_DIR` 自定义时使用该目录。恢复会回到备份时点，之后的交易必须人工核对，不存在自动合并恢复。本轮未提供自动恢复命令或恢复界面。

快照返回全部已保存流水，确保修改旧记录也能正确回算；尚无服务端分页，大量记录需要下一阶段优化。月度预算独立存储，`snapshot(month)` 可指定月份，缺省为服务器当前本地月。

参考：[Node.js 24 SQLite API](https://nodejs.org/docs/latest-v24.x/api/sqlite.html)。Node 24 的 `node:sqlite` 仍可能显示实验特性警告。
